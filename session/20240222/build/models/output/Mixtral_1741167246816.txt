L'hiver est arrivé, la neige étincelle,
Un manteau blanc recouvre le sol.
Les arbres endormis, dans le froid qui gèle,
Attendent patiemment le retour du soleil.

Le feu crépite dans la cheminée,
La chaleur réconfortante nous enveloppe.
Les vitres s'embuent, la nuit est tombée,
On entend les flocons qui s'abattent sur les toits.

Les enfants rient en faisant des anges,
Les joues roses, les yeux qui brillent.
Les paysages sont silencieux et étranges,
Comme figés dans le temps qui s'arrête.

L'hiver est magique, il nous fait rêver,
Il nous fait voyager dans un monde féerique.
On oublie le froid, on oublie de greloter,
Car l'hiver est beau, il est magnifique.
